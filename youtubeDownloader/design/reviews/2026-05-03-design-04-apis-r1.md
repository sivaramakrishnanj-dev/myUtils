# Review: Design — 04-apis.md — round 1

**Scope:** `design/04-apis.md` at commit `4088d0f`. Fourth Phase 2 Design artifact. Covers four external contracts consumed (InnerTube, video CDN, timedtext, thumbnail), one external contract invoked (ffmpeg CLI), three contracts provided (CLI, library API, temp-file), and a summary inventory.

---

## Review notes

No blocking, major, minor, or nit comments. Draft approved as-is.

**What was verified:**

- **Prose/schema boundary respected.** The doc is explicit that wire-format contracts (§ 1.1 InnerTube, § 1.3 timedtext) have authoritative schemas in `06-formal/` (Phase 3), with this prose in a descriptive role. Non-wire contracts (CLI flags, library API, ffmpeg command line) are authoritative here. No double-specification.
- **InnerTube contract (§ 1.1) is complete.** Request headers, request body, consumed response fields, and error-response → exit-code mapping are all enumerated. The "consumed fields only" note (per ADR 0004) is called out, matching the `additionalProperties: true` posture the Phase 3 schema will codify.
- **ffmpeg command lines (§ 2.1) are exact and copy-pasteable.** Flag-by-flag explanation for mux (`-c copy -map 0:v:0 -map 1:a:0`) and MP3 transcode (`-c:a libmp3lame -b:a 192k`). Version probe regex is specified. Signal handling (5s SIGTERM grace before SIGKILL) matches `02-architecture.md` § 5.
- **CLI flag table (§ 3.1.2)** — 15 flags with names, types, defaults, and descriptions. Names are declared final as of this Phase 2 lock; Phase 5 cannot rename without a new review round. This is the kind of commitment that lets tests start asserting against flag names in Phase 3 without fear.
- **Exit-code table (§ 3.1.4)** — canonical from AC-5.2 plus 130/143 for signals. Matches the `ErrorMapper` contract in `02-architecture.md` § 3.
- **Library API (§ 3.2)** — single entry point, 11-subclass exception hierarchy (1:1 with AC-5.2 categories per AC-9.4), builder-pattern fluent request construction, thread-safety contract explicitly documented. The `exitCode()` method on each exception lets the CLI module map without reflection or string-matching.
- **Thread-safety contract (§ 3.2.5)** — explicitly states that one `YoutubeDownloader` instance is safe across threads because `download(...)` creates per-call state. This is the hook US-9 (library embedders) need to build server-side job runners on top of the library.
- **SLF4J contract (§ 3.2.6)** — library does not bundle a backend; CLI ships `slf4j-simple`. Logger names follow `com.srk.myutils.yd.core.<ComponentName>` so operators can configure per-component levels.
- **Temp-file contract (§ 3.3)** is clear about the "retained on failure, cleaned on success" asymmetry from `02-architecture.md` § 5 and discourages embedders from coupling to filenames inside `.yt-tmp/`.
- **Contract inventory (§ 4)** — seven contracts total, each pinned at Phase 2 with a pointer to where its schema (if any) lives in Phase 3.
- **Cross-reference integrity** — 29 AC refs, 13 NFR refs all cross-checked against `00-requirements.md`.
