## P1 — Clean dependencyManagement pattern

- **Location:** `pom.xml` (parent) — `<properties>` + `<dependencyManagement>` sections; `yt-core/pom.xml` — `<dependencies>` section
- **Severity:** Praise
- **Category:** Readability
- **Reviewer comment:**
  Textbook multi-module Maven pattern: all 7 version properties pinned in the parent `<properties>`, `<dependencyManagement>` in the parent with `${...}` references, child declares deps versionless. This prevents version drift across modules and makes upgrades a single-property change. Clean Code (Martin) — single source of truth for each version.

## P2 — ADR traceability in POM comments

- **Location:** `pom.xml:36`, `pom.xml:42`, `yt-core/pom.xml:14`, `yt-core/pom.xml:18`
- **Severity:** Praise
- **Category:** Readability
- **Reviewer comment:**
  Every dependency group has a comment citing the governing ADR or SHARED.md section (`<!-- HTTP — ADR 0002 -->`, `<!-- JSON — ADR 0004 -->`, `<!-- Logging — SHARED.md § 3 -->`). This makes it trivial for a future maintainer to trace why a dependency exists. Good practice.

## P3 — Test-scope discipline in dependencyManagement

- **Location:** `pom.xml:55–72` — JUnit, AssertJ, jqwik entries
- **Severity:** Praise
- **Category:** Reuse
- **Reviewer comment:**
  Declaring `<scope>test</scope>` in `<dependencyManagement>` means child modules inherit the scope automatically — a child that forgets to write `<scope>test</scope>` still gets test scope. Prevents accidental production-classpath leakage of test libraries.

## m1 — Missing `<relativePath>` in child parent block

- **Location:** `yt-core/pom.xml:6–10` — `<parent>` block
- **Severity:** Nit
- **Category:** Readability
- **Reviewer comment:**
  Maven defaults `<relativePath>` to `../pom.xml`, which is correct for this layout. Adding `<relativePath>..</relativePath>` explicitly would make the parent resolution self-documenting and suppress the Maven 4.x deprecation warning about implicit relative paths. Not required for correctness.
- **Suggested fix:**
  ```xml
  <parent>
      <groupId>com.srk.myutils.yd</groupId>
      <artifactId>youtube-downloader</artifactId>
      <version>1.0.0</version>
      <relativePath>..</relativePath>
  </parent>
  ```
