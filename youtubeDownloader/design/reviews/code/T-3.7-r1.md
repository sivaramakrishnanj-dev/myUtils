## C3 — Empty-string ffmpegLocation treated as present

- **Location:** `Cli.java:79` — `Optional.ofNullable(ffmpegLocation)` + `YoutubeDownloader.java:120` — `request.ffmpegLocation().ifPresent(loc -> LOGGER.info(...))`
- **Severity:** Minor
- **Category:** Correctness
- **Spec citation:** AC-13.2
- **Reviewer comment:**
  When the user passes `--ffmpeg-location ""` (empty string), picocli sets `ffmpegLocation = ""`, and `Optional.ofNullable("")` produces `Optional.of("")` — a present but empty value. The log line fires: `"Using custom ffmpeg location: "`. More importantly, when T-3.8 wires this into `FfmpegMuxer`, an empty string would be passed to `ProcessBuilder` as the ffmpeg binary path, producing a confusing "cannot run program" error instead of the clean AC-13.2 message. Consider normalizing: `Optional.ofNullable(ffmpegLocation).filter(s -> !s.isBlank())` in `Cli.call()`. This is not blocking because T-3.8 hasn't landed yet and the empty-string invocation is an edge case, but fixing it now avoids a downstream surprise.
- **Suggested fix:**
  In `Cli.java:79`, change `Optional.ofNullable(ffmpegLocation)` to `Optional.ofNullable(ffmpegLocation).filter(s -> !s.isBlank())`.

## C4 — Compact constructor does not validate ffmpegLocation for null

- **Location:** `DownloadRequest.java:34` — compact constructor
- **Severity:** Minor
- **Category:** Correctness
- **Spec citation:** Effective Java item 49 (check parameters for validity)
- **Reviewer comment:**
  The compact constructor validates `maxHeight >= 0` but does not reject `ffmpegLocation == null`. A caller passing `null` instead of `Optional.empty()` would create a record that NPEs on any `.ffmpegLocation()` access. The existing fields (`url`, `output`, `listener`) also lack null checks, so this is a pre-existing pattern — not introduced by T-3.7. Flagging as Minor because the new field follows the existing convention; a blanket null-check sweep is a separate cleanup task.
- **Suggested fix:**
  Add `Objects.requireNonNull(ffmpegLocation, "ffmpegLocation")` to the compact constructor (alongside similar checks for `url`, `output`, `listener` if desired).
