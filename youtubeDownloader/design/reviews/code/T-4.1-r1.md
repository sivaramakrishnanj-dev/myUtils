## C1 — `noAsr` check fires without verifying ASR tracks match the target language

- **Location:** `FormatSelector.java:100-106` — `selectForLanguage` method
- **Severity:** Blocker
- **Category:** Spec-Adherence
- **Spec citation:** AC-7.4: "IF the only available captions are ASR AND `--no-asr` was passed"; AC-8.3: "IF `--lang <code>` is given AND no caption track matches `<code>`"
- **Reviewer comment:**
  The `noAsr` guard fires unconditionally when no manual track matches the target language, without first checking whether any ASR track matches the target either. Two incorrect behaviors result:
  (a) `tracks=[manual("fr"), asr("de")]`, `requestedLang="en"`, `noAsr=true` → throws AC-7.4 message ("only auto-generated captions available") when in fact manual tracks exist (in another language) and no track at all matches "en". Correct path: AC-8.3 ("no caption track available for language 'en'. Available: fr, de").
  (b) `tracks=[manual("fr")]`, `requestedLang="en"`, `noAsr=true` → throws AC-7.4 message when there are zero ASR tracks globally. Correct path: AC-8.3.
  AC-7.4 should fire only when ASR tracks matching the target language exist but `--no-asr` prevents their use.
- **Suggested fix:**
  Move the `noAsr` check to after the ASR lookup. If ASR tracks match the target AND `noAsr` is true, throw AC-7.4. If neither manual nor ASR match, fall through to AC-8.3.

## C2 — Dead code: `anyManualExists` computed but never used

- **Location:** `FormatSelector.java:101` — `selectForLanguage` method
- **Severity:** Minor
- **Category:** Readability
- **Spec citation:** Clean Code (Martin) — dead code obscures intent.
- **Reviewer comment:**
  `boolean anyManualExists = tracks.stream().anyMatch(t -> !t.isAsr());` is computed but never referenced. This appears to be a leftover from an earlier draft where the AC-7.4 condition was intended to check global manual-track existence. Either use it in the corrected `noAsr` logic (per C1) or remove it.
- **Suggested fix:**
  After fixing C1, this variable may become useful for the corrected condition. If not needed, delete it.

## C3 — Missing test: `noAsr=true` with manual tracks in other languages

- **Location:** `FormatSelectorCaptionBehaviorTest.java` — `NoAsrRefusal` nested class
- **Severity:** Blocker
- **Category:** Testing
- **Spec citation:** Pinned tenet 1: "Tests are not optional. New or modified public/business logic without a test = Blocker."
- **Reviewer comment:**
  The `NoAsrRefusal` test only covers the case where the sole track is ASR in the target language. It does not cover the edge case exposed in C1: `noAsr=true` with manual tracks in other languages but no track (manual or ASR) matching the target. This is the scenario where AC-7.4 vs AC-8.3 disambiguation matters. Without this test, the C1 bug would not have been caught.
- **Suggested fix:**
  Add a test: `tracks=[manual("fr"), asr("de")]`, `requestedLang="en"`, `noAsr=true` → expects `CaptionUnavailableException` with AC-8.3 message (contains "Available:" and the requested language code), NOT the AC-7.4 message.
