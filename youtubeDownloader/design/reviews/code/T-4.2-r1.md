## C3 — Timeout verification uses reflection

- **Location:** `CaptionDownloaderBehaviorTest.java:131`
- **Severity:** Minor
- **Category:** Testing
- **Spec citation:** NFR-CAPTION-DOWNLOAD-TIMEOUT
- **Reviewer comment:**
  The `create_configures10SecondTimeouts` test accesses `httpClient` via reflection. This is fragile if the field is renamed. OkHttp's `connectTimeoutMillis()`, `readTimeoutMillis()`, `callTimeoutMillis()` are public on `OkHttpClient` — the test could expose the client via a package-private getter or accept the reflection trade-off. Given that the field name is stable and the test is valuable, this is acceptable but worth noting.
- **Suggested fix:**
  Consider adding a package-private `OkHttpClient client()` accessor on `CaptionDownloader` for test use, or accept the reflection approach as-is. Not blocking.

## C4 — `Accept: */*` header not in spec but harmless

- **Location:** `CaptionDownloader.java:63`
- **Severity:** Nit
- **Category:** Readability
- **Reviewer comment:**
  The `.header("Accept", "*/*")` is not required by any AC or NFR. OkHttp sends no `Accept` header by default (which is equivalent to `*/*` per HTTP semantics). Harmless but adds a line with no spec backing. Consistent with defensive HTTP practice — acceptable.
