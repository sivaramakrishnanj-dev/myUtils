## C3 — 11-argument record constructor — growing positional-arg smell

- **Location:** `yt-core/src/main/java/com/srk/myutils/yd/core/DownloadRequest.java`
- **Severity:** Minor
- **Category:** API-Design
- **Spec citation:** AC-9.1 (library embedder ergonomics)
- **Reviewer comment:**
  The record now has 11 positional parameters. Java records don't support named parameters, so every call site must count positions carefully — the 12 existing test files that needed updating demonstrate the fragility. *Effective Java* item 2 (builder pattern for many constructor parameters) applies. This is acceptable for now since the record is internal plumbing and the `audioOnly(...)` factory method exists, but a builder should be introduced before M5 adds more flags.
- **Suggested fix:**
  No action required for T-4.6 (plumbing task). Flag for T-5.1 or a dedicated refactoring task: introduce `DownloadRequest.builder()` with sensible defaults.
