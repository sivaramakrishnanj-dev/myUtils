## C1 — Clean resolution of the `--video` / `--audio-only` conflict

- **Location:** `Cli.java:184–196` (`computeEffectiveVideo()`)
- **Severity:** Praise
- **Category:** Correctness
- **Spec citation:** AC-2.5, 04-apis.md § 3.1.2
- **Reviewer comment:**
  The method handles all four cases cleanly: (1) `audioOnly` → force false + WARN if explicit `--video`; (2) explicit `--video` → honour it; (3) transcript/thumbnail-only → default false; (4) otherwise → default true.
