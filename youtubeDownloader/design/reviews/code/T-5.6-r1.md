## C6 — Minor: "Common commands" section shows `--video --audio-only` together without explaining the interaction

- **Location:** `README.md:55`
- **Severity:** Minor
- **Category:** Readability
- **Spec citation:** `04-apis.md` § 3.1.2, `05-operations.md` § 2.1
- **Reviewer comment:**
  The command `$JAR --video --audio-only --audio-format mp3 --transcript --thumbnail "URL"` is documented in `05-operations.md` § 2.1 as the "everything at once" invocation, so it's spec-correct. However, the flag table says `--audio-only` "disables video" — a reader seeing both `--video` and `--audio-only` on the same line may be confused. The comment "Everything: video + audio + transcript + thumbnail" helps, but a one-line note explaining that `--video` explicitly re-enables video output alongside `--audio-only` would improve clarity.
- **Suggested fix:**
  Add a brief inline comment or a note below the command:
  ```bash
  # Everything: video + separate audio (MP3) + transcript + thumbnail
  # (--video re-enables video output alongside --audio-only)
  ```
