## C1 — Hardcoded jar path couples tests to a specific version string

- **Location:** `FatJarSizeIT.java:22` and `FatJarStructureIT.java:22`
- **Severity:** Minor
- **Category:** Readability
- **Reviewer comment:**
  Both classes hardcode `Path.of("target/youtube-downloader-1.0.0.jar")`. When the version bumps to `1.1.0` or `2.0.0`, both tests break silently (file-not-found assertion). A glob or Maven-filtered property (`${project.build.finalName}`) would decouple the test from the version string. However, this is intentional coupling for MVP (version is `1.0.0` and stable per `05-operations.md` § 6.3), so it is Minor, not Major.
- **Suggested fix:**
  Accept as-is for MVP. If version churn becomes real, extract a shared constant or use `Files.list(Path.of("target")).filter(p -> p.getFileName().toString().matches("youtube-downloader-.*\\.jar"))`.

## C2 — Lower-bound sanity check is a good defensive assertion

- **Location:** `FatJarSizeIT.java:24`
- **Severity:** Praise
- **Category:** Testing
- **Reviewer comment:**
  The 1 MB lower bound catches the case where the shade plugin silently produces an empty or stub jar. This is a thoughtful guard against false-green CI. Clean Code — "test what can go wrong, not just what should go right."

## C3 — JarFile structural validation is thorough

- **Location:** `FatJarStructureIT.java:30–43`
- **Severity:** Praise
- **Category:** Testing
- **Reviewer comment:**
  Opening the jar as a `JarFile`, verifying the manifest, asserting `Main-Class`, and checking entry count > 10 covers ZIP integrity, manifest presence, and non-emptiness in one concise test. Good use of `try-with-resources` for the `JarFile` handle.

## C4 — Main-Class assertion hardcodes the entrypoint class name

- **Location:** `FatJarStructureIT.java:38`
- **Severity:** Nit
- **Category:** Readability
- **Reviewer comment:**
  `"com.srk.myutils.yd.cli.Cli"` is hardcoded. This is intentional coupling — the shade plugin's `<mainClass>` and this test must agree. If they drift, the test catches it (which is the point). Acceptable as-is.
